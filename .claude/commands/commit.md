## Task

- Review the current git diff (staged and unstaged).

- Commit the changes using Conventional Commit format.

- Write only a one-line subject. No body or extended description.

- Split into separate commits when the changes cover distinct concerns.

- Don't add a Co-Authored-By trailer unless you wrote the code yourself.

- If the diff has any `console.log`, show file:line and ask: delete or keep? Wait for my answer.

- You can commit directly to the main branch.
